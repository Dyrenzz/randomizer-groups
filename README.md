# randomizer-groups
As a leisure time project, I created a group picker project inspired by my small program that I used to pick/generate random groups in my high school class. I then ended up improved it and took it into the next level by developing an app using Flutter.
# 🎯 Randomizer: Group Picker

![Flutter](https://img.shields.io/badge/Flutter-%2302569B.svg?style=for-the-badge&logo=Flutter&logoColor=white)
![Dart](https://img.shields.io/badge/dart-%230175C2.svg?style=for-the-badge&logo=dart&logoColor=white)

Sebuah aplikasi pengacak kelompok yang efisien, berawal dari proyek iseng saat SMA untuk membantu pembagian tim di kelas, kini dikembangkan lebih lanjut menggunakan **Flutter** untuk pengalaman pengguna yang lebih baik.

## 🚀 Fitur Utama
- **Quick Randomize:** Masukkan daftar nama dan tentukan jumlah kelompok secara instan.
- **Fair Distribution:** Algoritma yang memastikan pembagian anggota merata dan tidak bias.
- **Modern UI:** Tampilan bersih dan responsif berkat framework Flutter.
